# Maze Solver

迷路を生成し、Paintbrush / 右手法 / 左手法 / BFS / DFS / A* / マイクロマウス で解く様子を可視化する静的 Web アプリです。複数階層の迷路と階段移動に対応しています。元の `maze_game.py` は Tkinter 版として残し、GitHub Pages で公開できるようにブラウザ版を追加しています。

画面は 2 つのタブに分かれています。

- **迷路ソルバー**: 多階層迷路の生成と各種解法の可視化（従来の機能）
- **DFS-N 研究ラボ**: 「探索優先順位を方位で偏らせた DFS は、報酬が偏在する領域と方位が一致するとき BFS より早く報酬を回収できるか」を検証する実験環境

## 主な機能

- 多階層（最大5階）の迷路生成と、階段による階またぎ移動
- 6 種の解法アルゴリズム（Paintbrush / 右手法 / 左手法 / BFS / DFS / A*）のアニメーション可視化
- **シード指定**による再現可能な迷路生成（同一迷路でのアルゴリズム比較に）
- **ループ率（braiding）** で別解のある迷路を生成（壁伝い法と最短探索の差が見える）
- **全解法比較**: 経路長・探索セル数・所要時間・最短一致を一覧表で比較
- **バッチ検証**: 複数迷路で各解法の平均経路長・平均探索数・最短率を統計集計（非同期チャンク処理＋進捗バーでUIが固まらない）
- **探索ヒートマップ**: 探索順を寒色→暖色のグラデーションで可視化（カラースケール凡例つき）
- **マイクロマウス視点（霧）**: 視界が壁にさえぎられ、通った道・見えた道だけが明らかになる迷路（全階・縦並び／3D俯瞰／1階ずつ の全表示モードに対応）。矢印/WASD で人が手動で解けるほか、壁を少しずつ知りながらフラッドフィルで解く「マイクロマウス」探索アルゴリズムも搭載。往路は緑、引き返した道は橙で色分け表示
- **パラメータ掃引グラフ**: ループ率・階段密度を横軸に各解法の平均探索数を折れ線比較
- **CSV / JSON エクスポート**: バッチ・掃引の結果を外部解析向けに書き出し
- 表示モード切替（全階を平面で縦並び / 3D俯瞰で積層表示 / 1階ずつ）
- スクリーンリーダー向けの詳細アナウンス（aria-live）

## DFS-N 研究ラボ

2 つ目のタブは、偏在する報酬と方位バイアス付き探索の関係を検証する実験環境です（1 階層固定）。

- **報酬の偏在**: 中心 (x, y)・半径 r の円領域に報酬を集中配置。集中率 0% で一様分布（対照条件）
- **DFS-N**: 近傍の展開順を「進行方向とバイアス方位の内積」で決める深さ優先探索。0°=右、90°=上
- **回収曲線（図1）**: 探索コストに対する報酬回収率。指標は nAUC（曲線下面積、大きいほど早い）
- **バイアス角スイープ（図2）**: 22.5° 刻み 16 方位の nAUC を極座標で表示。BFS の等方ベースライン円と報酬領域の実方位を重ねる
- **マイクロマウス検証（図3）**: 未知迷路を走るロボットで同じ効果を検証。「大まかなゴール座標（＝領域）だけ与える」応用も測る。単位は**実移動歩数**
- **対照条件を明示**: BFS だけでなく「等方 DFS（順序ランダム）」を対照に置く。固定順の DFS はそれ自体が方位バイアスを持つため、方位効果の分離には使えない
- **Greedy-領域（参考上限）**: `f(n) = (1−w)·g(n) + w·h(n)` の重み付き最良優先探索。DFS-N と同じ事前情報（領域の中心と半径のみ）を距離場として直接使う参考線で、貪欲度 `w`（`w=0` は BFS と一致）・距離（L1/L2/L∞）・領域の使い方（中心/縁）を UI で調整できる。定義の全文はページ内の「Greedy-領域の定義」に掲載
- **試行数の調整**: バイアス角スイープとマイクロマウス検証はそれぞれ 1〜200 試行。シードはベースシードから決定的に派生し、途中で中止すればそこまでの試行で集計する
- **限界も表示**: 参考上限が提案手法を上回りうること、事前情報が誤っている場合の逆効果、最短経路を保証しない点を UI に明記

## 使い方

`index.html` をブラウザで開くと動作します。ビルドや依存関係のインストールは不要です。

## テスト

迷路生成と解法アルゴリズムの単体テストは Node.js 標準のテストランナーで実行します（追加依存なし）。

```bash
npm test
```

## 公開

GitHub Pages は `.github/workflows/pages.yml` から `main` ブランチへの push 時にデプロイします。
公開 URL は `https://ry32767.github.io/MazeCreator/` です。

## ファイル

- `test/maze.test.js`: 迷路生成と解法の単体テスト
